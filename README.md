# SOLICITUD-PRENSA-FLANDES

Web (no app) para que las personas registradas por la Oficina de Comunicaciones de la Alcaldía de Flandes pidan apoyo (fotos, video, piezas gráficas, perifoneo, publicaciones) y sigan en qué va cada solicitud.

- Se entra con el enlace que manda Comunicaciones por WhatsApp o con el número de WhatsApp registrado.
- Las solicitudes llegan a COMUNICACIONES-FLANDES marcadas *Externa*.
- Backend: FLANDES-CORE (`SolicitudExterna.gs`, rutas `SOLICITANTE.*`).
